# Projeto Governo Eletrônico — Informa.BR

## Identificação

**Disciplina:** Arquitetura e Desenho de Software (FGA0208)
**Turma:** 02 — 2026.2
**Grupo:** 05
**Entrega:** 03 — Padrões de Projeto

## Contextualização

O grupo utiliza o [Informa.BR](https://informabr.cgu.gov.br/) como objeto de estudo de arquitetura e desenho de software, mantendo a continuidade temática da Entrega 02.

Nesta etapa, o objetivo é avaliar e demonstrar **decisões de design** com padrões GoF. A modelagem e o código elaborados são **propostas acadêmicas do grupo**, e não uma afirmação sobre a arquitetura interna real do portal.
