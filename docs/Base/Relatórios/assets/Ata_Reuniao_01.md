## 2. Assuntos Discutidos

### 2.1. Escopo da Entrega

O fluxo do **Informa.br** escolhido para o trabalho é o de **busca**. A partir dele, o grupo identifica um problema e escolhe o padrão de projeto que o resolve. Fabio sugeriu o padrão **Facade**, pois o fluxo de busca resultaria em um sistema mais simples. Não houve discordância e por isso esse foi o padrão escolhido, para que pudessemos dar continuidade a elaboração do modelo, código e vídeo.

### 2.2. Divisão do Trabalho entre os Integrantes

Pedro levantou a preocupação de garantir que todos participem de todas as frentes. Ele observou que, se cada integrante ficasse com uma frente (um com o código, outro com o vídeo, outro com o modelo), a divisão não seria adequada. O grupo concordou que **todos devem fazer tudo**, como na entrega anterior.

Foram discutidas duas abordagens:

- **Versões independentes:** todos implementam o mesmo padrão e comparam as diferenças no final. Pedro observou que, na entrega anterior, os diagramas escolhidos eram diferentes; desta vez seriam o mesmo padrão em todas as versões.
- **Evolução incremental:** um integrante produz uma versão e o próximo a evolui, tanto na modelagem quanto no código.

Após considerar o feedback recebido anteriormente, o grupo optou pela **evolução incremental**. Relembrando que a professora havia comentado a ausência de revisão entre os integrantes. Uma revisão teria permitido perceber o desequilíbrio entre os diagramas de pacotes e de componentes. A evolução permite que cada integrante revise o trabalho do anterior.

- Foi sugerido explicar também por que o padrão Facade foi escolhido em vez dos demais, como fez outro grupo cujo material foi consultado.
